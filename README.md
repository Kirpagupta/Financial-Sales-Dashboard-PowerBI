# Financial Sales Dashboard using Power BI

## 📌 Project Overview

This project is an interactive Financial Sales Dashboard developed using Microsoft Power BI. The dashboard provides valuable business insights by visualizing sales, profit, units sold, customer segments, product performance, and geographical sales distribution. It enables users to explore the data through interactive filters and make data-driven decisions.

---

## 🎯 Objective

The objective of this project is to design an interactive dashboard for business stakeholders that presents key performance indicators (KPIs), sales trends, and financial insights in an easy-to-understand format.

---

## 🛠 Tools Used

- Microsoft Power BI Desktop
- Financial Sample Dataset (CSV)

---

## 📊 Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Units Sold KPI
- Yearly Sales Trend Analysis
- Profit by Product
- Sales by Country (Map Visualization)
- Sales by Customer Segment
- Monthly Sales Analysis
- Interactive Slicers for:
  - Year
  - Country
  - Segment

---

## 📈 Key Insights

- The dashboard provides an overview of overall business performance.
- Users can compare product profitability.
- Sales distribution across different countries is visualized using a map.
- Monthly and yearly sales trends help identify business growth.
- Customer segments can be analyzed using interactive filters.
